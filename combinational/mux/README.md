# Multiplexers
This folder contains Verilog implementations and testbenches for mulitplexers.

## Multiplexers Included
- 2:1 Multiplexer
- 4:1 Multiplexer (dataflow model)
- 4:1 Multiplexer (behavioral model)

## Simulation
The testbenches were simulated using Icarus Verilog.

`$dumpfile` and `$dumpvars` are used in the testbenches to generate VCD waveform files, which can be viewed using GTKWave.

The generated `.vcd` files is not included in this repository.
